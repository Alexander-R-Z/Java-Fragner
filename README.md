# Java-Fragner

Meine Sammlung der Beispielprogramme und Übungsaufgaben aus den Java-Vorlesungen von Fragner.

## Voraussetzungen

Installierte JDK Version 17 oder höher.

## Programme kompilieren und ausführen

Kompilieren einzelner Aufgaben direkt über die Kommandozeile:

```bash
# Im gewünschten Aufgabenordner ausführen
javac aufgabe1.java
```

Ausführen einzelner Aufgaben direkt über die Kommandozeile:

```bash
# Im gleichen Aufgabenordner ausführen (da wo die .class datei erstellt wurde)
java aufgabe1
```

## Ressourcen

- Moodle-Kurs: [Programmieren in Java, WiSe 2023/24, Fragner](https://moodle.hs-hannover.de/course/view.php?id=24635)
- `PDFs/`-Ordner für Aufgabenblätter, Formelsammlungen und das Vorlesungsskript

Dieses Repository dient in erster Linie als Lernunterlage.
